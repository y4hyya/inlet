# Addresses

Every address here is exported by the SDK, as `mainnetChains`, `mainnetDeployments` and `mainnetProtocols` for mainnet and as `testnetChains`, `testnetDeployments` and `testnetProtocols` for testnet, generated from the config files in the repository.

## Mainnet

Live since 2026-10-12. The hub sits on Arc mainnet and Arbitrum One is the first destination, with Aave V3 and the exit rail. Every contract is owned by the deployer key `0x31b1610Ec633Ed09Ce15dfDf697DD631daa3Bd02`. The hub and the receiver share an address because each was that key's first transaction on its chain; they are different contracts on different chains.
